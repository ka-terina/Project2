## Функционал

### Функция для фильтрации списка операций
Чтобы запустить функцию введите:
```
filter_by_state(new_lst, state="EXECUTED")
```
Где *new_lst* это ваш список с операциями, *state* параметр для фильтрации.

### Функция для сортировки списка операций по дате
Чтобы запустить функция введите:
```
sort_by_date(new_lst, reverse=True)
```
Где *new_lst* это ваш лист для сортировки, параметр по умолчанию reverse=True сортировка по убыванию.

### Функция для маскировки номера карты
Чтобы запустить функцию введите:
```
get_mask_card_number(number)
```
Где *number* это ваш номер карты для маскировки

### Функция для маскировки номера счета
Чтобы запустить функцию введите:
```
get_mask_account(number)
```
Где *number* это ваш номер счета для маскировки

### Функция для вывода даты из полученной строки
Чтобы запустить функцию введите:
```
get_date(date)
```
Где *date* это ваша строка с датой

### Декоратор для логирования выполнения функции
Пример использования
```
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)
```
Пример вывода в консоль либо в файл

Вывод если функция работает корректно
```
Start work
my_function 1.0
End work
```
Вывод если функция выдает ошибку
```
Start work
my_function error: ZeroDivisionError. Input: (2, 0), {}
End work
```
